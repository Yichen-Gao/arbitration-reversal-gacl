# Patch Result Provenance

These files are cached summaries for the optional heavy mechanism analysis.
They allow Figure 3 and the site-localization table to be reproduced without rerunning activation patching.

- `panel_a_qwen2_audio_aqa_scatter.csv`: per-sample patch-induced vs final-score displacement for a representative configuration.
- `panel_b_macro_mean_range.csv`: layer-resolved Spearman alignment summary across configurations.
- `table2_site_localization.csv`: peak rescue-rate summary for answer-side residual, audio span, and instruction-token sites.
